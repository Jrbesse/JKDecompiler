# Dev Log #1 — M2.5 arc: convert → light recovery → fit → acceptance gate

*November 28, 2026*

## What happened

The M2.5 light-recovery arc (#2 convert pipeline → #3 stage 1 grid recovery →
#13 stage 2 closed-loop fit → #17 gated end-to-end acceptance → #19 skyLight
130 default → #21 single-player validation → #25/#28 directional sun key →
#34/#35 lightmap-derived generator + quality-gated stage 1) landed across
Nov 21–25 and the Nov 26–28 generator/evidence push. This entry covers the
whole arc as a single thread, because the pieces only make sense in order:
the convert pipeline is what makes every downstream fit verifiable, the
stage-1/stage-2 split is what lets the fit be honest about what it recovered,
and the acceptance gate is what decides whether the fit counts at all.

The honest headline as of 2026-11-28: **the default path now passes the
acceptance gate on academy1, but only thinly — and the single-player maps
remain recovered-nothing**. Both numbers are real; both are written down in
the docs, not papered over.

## What changed

### Convert pipeline (PR #2, Nov 21–22)

`q3map2 -game ja -convert` orchestrator (`ConvertOrchestrator`,
`JKDecompiler.Core`), with `.map` stats + a recompile-verify step. Notably:

- `q3map2` launch needed `LD_LIBRARY_PATH` pinned to the `q3map2` directory
  (commit `26b61fa`) — the forked binary's sibling libs are not on a normal
  path, and conversion silently misbehaved without the pin.
- The launcher absolutizes the binary path and flushes async output events
  (`c34c633`) — a relative path + unflushed events used to produce flaky
  conversion output.
- RBSP record layout (80/148/30-byte structs) was fixed earlier (PR #1,
  `b9fa548`) — the convert pipeline is only as good as the writer it feeds.

### Stage 1 — lightgrid recovery (PR #3, Nov 22, `32796fe`)

Recover point-light emitters from the lightgrid (grid seeding). Known-weak
from the start: on academy1 it produced 46 seeds and the fit kept 0 of them
(stage-A = ambient-only = 103.02). On the SP maps it over-produces and, for
vjun1, fails outright.

### Stage 2 — closed-loop light fit (PR #13, Nov 22–24)

The big one: `LightFit.Fit` + `fit-lights` CLI (`a97431b`). What it carries:

- Dense original-driven sample set (`BuildOrigPairs`, `135000a`) — real
  original-driven probe sampling, not a grid of guesses.
- Probe dummy spans the map; dead points masked per-field (`6081b47`).
- Probe dummy truncation fix: `light` format `0.#` → `0.###` (`db6534f`).
- JKA quadratic falloff bug (Bug 3) fixed for the dummy probe light
  (`f10b911`).
- Probe-parity dummy on every compile + brightness sky-mask (`b0f2509`).
- Loose plane match + honest ambient fill; stage-A zero-fill fix (`0bc4e65`).
- Sample candidates through their own UV, not the probe's (`4a5f7db`).
- Lawson-Hanson NNLS; solid-aware seed push (`0d4454c`).
- Always-write residual diff + honest exit code on gate fail (`21b24dc`).
- Sky bake: re-texture real sky brushes to overlay skylight shader
  (`d8a1c79`); spatial A/B wash basis + calibrated skyLight value (`0c4707b`);
  bake-consistent model (wash as baked + constant), gain → diagnostic
  (`7052c65`); skydbg: full-set L1s (the masked-set L1 misread 65.2 vs true
  103.0, `2dcc4a8`).
- Stage-A gate post-mortem dump (`JKD_STAGEA_DBG`), stale-scale sync,
  `Fitrun31DiagTest` (`a860414`).
- 5b joint NNLS over all fields replaces greedy hard selection (`8d16ba3`);
  symmetrize the 5b normal matrix (`384485e`); gate radius-candidate fields
  with `have[]` (`450a052`).
- Fit gate: no vacuous pass — require non-empty survivor set and a 2.0 L1
  margin (`3228760`).
- Prune dead seeds only (scale 0) in the joint NNLS path (`d3de8f9`).

### Acceptance gate (PR #17, Nov 23–25)

`EndToEndFitTest` (tests/JKDecompiler.Tests) — convert → fit-lights →
assert `kept > 0` and `ErrorFinal < ErrorAmbientOnly − 2.0`. The ≥ 2.0 L1
margin is the enforced bar; academy1's measured: ambient-only 103.02 →
final 73.25 with the 2026-11 fit (−29.77). Loud skip (not silent pass)
when fixtures/q3map2/JKA_GAME_DIR are absent — CI (no fixtures) cannot
silently green-light a broken fit.

### Directional sun key (PR #25, Nov 25, `5c6976f` / `e564cbe`)

Adds a directional sun key to the fit/sky overlay shader — replaces skyLight
(the radial key) with the game's own directional wash: `sun <intensity>
<degrees> <elevation>` inside the shader, plus a sky bake that re-textures
real sky brushes to the overlay shader. The sun path (`--sun-intensity N`,
degrees 120°/elevation 40°, intensity 0 = default behavior) is **opt-in**,
not the default. Reference: `textures/mp/h_yavin` carries
`sun 1.000000 0.540000 0.629266 180 120 40`. The sun key replaces skyLight —
the game's own directional shaders carry the sun, so the overlay must not
double-count it.

carried by the sun key direction, not by the fit's interior stack.
Shape check is "verified by construction", not by lightmap profile.

### Lightmap-derived generator (Nov 26–27, `d4e5ca7` → `1802b14` → `76ca59d` → `6444237` → `abc6018`)

New default seed path (`LightmapSeedGenerator`, in-repo, replaces stage-1
grid seeding as the default): per-face bright-texel 8-connected components
(≥ 30 texels, mean-RGB > 8) → 60u cross-face union-find clustering → strip
split (extent > 500u AND aspect > 1.5 — gap-split when one exists, equal-width
segments otherwise) → 4D coordinate descent over (x, y, z, R) against the JKA
quadratic falloff (closed-form L per (x,y,z,R), L1 objective over bright
texels + same-face dim tails) → keep corr ≥ 0.65 and L ≥ 30 (wide wall-band
segments exempt — a single sphere cannot fit a 2-wide strip) → 0.6·min-radius
dedupe.

Default path went from **gate-fails** (2026-11-26, `6444237`) to **gate-passing**
(2026-11-27) via one specific fix (`abc6018`, PR #34):

1. **Apex placed behind the wall plane** (InitHeight 60 → −40, descent band
   projN ∈ [−40, +80]) — the room-side apex at +60 sat 0.5x the brightness at
   the wall, collapsing the per-light field into a single peak and zeroing
   the joint NNLS. Behind-wall start + tight descent band puts the field's
   center of mass on the bright band itself.
2. **Dead-seed-only prune in the joint NNLS** (kept since `d3de8f9`): any
   light with zero joint scale is dropped; everything else kept.

Gate-passing verdict (2026-11-27, verified with `JKD_E2E_QUICK=1` on academy1,
11m 47s): kept 1/8 (lm_5, south-wall seed, dE=4.65), stageA final **94.73**
vs ambient-only 103.47 (−8.7, better than the −2.0 bar). **Caveat**: the
old external-9-seed control was kept 9/9 with final 73.98 — a much healthier
margin. The default path is gate-passing, not production-parity-passing.

### Stage-1 quality gate (PR #35, Nov 27, `102d73d`)

`LightRecovery` now orders accepted seeds best-first by the same metric
stage 2 uses (level consistency ascending, then forward-ray fraction
descending, then evidence size descending) and accepts an optional
`--max-seeds N` cap; the CLI truncates to the top N and re-numbers. Default
(`--max-seeds 0`) is unchanged: all seeds kept, now best-first (previously
peel order). Verified on all three SP maps:

| Map | Default (all) | `--max-seeds 25` | `--max-seeds 10` |
|---|---|---|---|
| t1_sour.bsp | 263 seeds (best-first: #0 consistency=0.18, #24=0.44-ish) | top 25 — #0 cells=14 rayMed=7.8 t+=100% consistency=0.18 | top 10 |
| t2_rancor.bsp | 363 seeds (best-first: #0 consistency=0.15) | top 25 — #0 cells=26 rayMed=19.5 t+=100% consistency=0.15 | not run |
| vjun1.bsp | INVALID grid (unchanged) | — | — |

The top-10 seeds on t1_sour are all 100%-forward, 0.18–0.39 level-consistency,
≤ 20.6u median ray distance — the quality gate selects a small, coherent set
instead of 263 near-indistinguishable seeds. **Still not validated**: a
stage-2 fit with the quality-gated seeds (the prior capped run already used
the same 25 seeds and kept 0/25 with L1 179.68 → 179.68 — the failure is in
the fit, not the seed list).

  pos/r/color) + writes `seeds.json`.

  40°) on the fit/sky shader path; the game's own directional textures carry
  the sun key (e.g. `textures/mp/h_yavin`).

  truncates best-first and re-numbers.
