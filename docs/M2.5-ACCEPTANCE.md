# M2.5 Acceptance Criteria — Light-Entity Recreation

Goal: recreate the light entities (and their intensity/color/radius) that the
original game baked into the lightmap, from an RBSP, without carrying original
light data over.

## The gate

An end-to-end run must beat ambient-only by a **≥ 2.0 L1 margin**:

- **Kept lights > 0** — at least one recovered light survives pruning, and
- **ErrorFinal < ErrorAmbientOnly − 2.0** (area-weighted L1/channel, in the
  units reported by the fit: academy1 measured ambient-only = 103.02, final =
  73.25 with the 2026-11 fit, i.e. −29.77, better than the −2.0 bar).

`LightFit.GateMarginL1` (default 2.0) enforces the same margin at stage A
internally; the test asserts it end-to-end so a regression that silently
empties the light set (or regresses the fit) fails the suite.

## Known limitation (as of 2026-11-26): the default path still fails the gate

The default seed path is **lightmap-derived seeds** (`LightmapSeedGenerator`,
in-repo). As of 2026-11-26 the generator was rewritten v6b-style: per-face
bright-texel 8-connected components (≥ 30 texels, mean-RGB > 8) → 60u
cross-face union-find clustering → strip aspect split (extent > 500u and
aspect > 2.5) → 4D coordinate descent over (x, y, z, R) against the JKA
quadratic falloff (closed-form L per (x,y,z,R), L1 objective over bright
texels + same-face dim tails) → keep corr ≥ 0.65 and L ≥ 30 → 0.6·min-radius
dedupe. Output: 14 seeds on academy1 (vs 4 before, 3 in the old v6b scratch
script). External seeds via `JKD_E2E_SEEDS=<path>`/`--seeds` still work and
remain the measured-good path (fitrun34: 103.02 ambient → 73.25 final,
kept 4 on a hand-tuned 9-seed wall-washer set, ~39 min — that is the evidence
the gate passes, and a 9-light external set still gate-passes as of
2026-11-26 with `JKD_E2E_QUICK=1`: 9m 2s, kept>0).

**The lightmap-derived default STILL does not pass the gate** (verified
2026-11-26, JKD_E2E_QUICK=1 on academy1, both selectors:
joint NNLS (default) and JKD_SELECT_GREEDY=1 — both kept=0, stageA =
ambient-only = 103.47, ~13 min). The v6b scratch script on the same fixture
recovers only 3 floor pools (m6_00/01/02); every wall-band cluster fails its
corr gate (0.014–0.301) and most wall clusters report "core too small" after
the strip split — so the wall-washer partition is NOT recoverable by this
approach on academy1. The 4 well-separated seeds and the whole 14-seed set
fail identically. This is the same documented multi-light blocker (v40:
single-light control passes 97.57 ≤ 101.02 — fields are sound, per-light
selection over overlapping pools is not; joint NNLS was added to fix the
greedy failure and still zeroes these seeds). The shipped default is
strictly worse than the measured 9-seed external file — do not claim the
gate passes on the new default.

The acceptance gate therefore cannot be closed from the generator alone
without either (a) a different partition of the wall-washers (hand-tuned,
owner sign-off — the 9-seed set is the only measured-good partition) or
(b) a fix to the per-light selection that survives a deep wall band of
collinear seeds (out of scope for this slice).

## How it runs

`EndToEndFitTest` (tests/JKDecompiler.Tests) exercises the full pipeline:

1. **convert** — `ConvertOrchestrator` (RBSP → .map via `q3map2 -game ja -convert`)
2. **fit-lights** — `LightFit.Fit` (lightmap-derived seeds by default;
   stage-1 grid seeds via `--stage1`; external seeds via `--seeds`;
   per-light single compiles; joint NNLS fit; position refinement; radial fit)
3. asserts `kept > 0` and `ErrorFinal < ErrorAmbientOnly − 2.0`

### Environment requirements (loud skip, not silent pass)

| Env var | Required | Meaning |
|---|---|---|
| `JKA_BSP_FIXTURES` | yes | directory of .bsp fixtures; the test prefers `academy1.bsp` |
| `tools/q3map2` (or `JKD_Q3MAP2`) | yes | the forked q3map2 binary |
| `JKA_GAME_DIR` | yes | directory containing `base/` paks (q3map2 `-fs_basepath`) |

When any of the above is absent the test does not run anything — it passes
with a loud skip message (same pattern as `FixtureTests`). The gate is NOT
bypassable by absence of the CI env: the skip is loud, and CI (no fixtures)
cannot silently green-light a broken fit.

### Optional knobs

| Env var | Effect |
|---|---|
| `JKD_E2E_QUICK=1` | stage-A smoke: `--no-posfit --no-radfit` (skips the two expensive refinement passes; same assertions) |
| `--stage1` | opt out of lightmap-derived seeds; restore the stage-1 grid seeder (known-weak) as the default |
| `mkseeds <bsp> <outdir>` | CLI subcommand: prints the generated seeds (name/pos/r/color) + writes `seeds.json` |
| `JKD_E2E_SEEDS=<path>` | skip lightmap generation; external seeds JSON (same format as `--seeds`) |

### Cost

Full fit on academy1 compiles ~29 times, ~35–40 min (parallel=2). CI stays
green by skipping; local runs with fixtures exercise the real pipeline.

### Fixture note

Copyrighted JKA .bsp fixtures are never committed (JKA_BSP_FIXTURES gates
them, same as FixtureTests). The academy1.bsp used for the 103.02 → 73.25
numbers lives outside the repo.

## Directional sun path (opt-in, off by default — issue #18)

The default overlay keys skyLight (130, owner decision #16), radially
symmetric. The sun path (`--sun-intensity N`, degrees 120°/elevation 40°,
intensity 0 = default behavior) is opt-in and REPLACES the skyLight key —
the game's own directional sky shaders carry the sun key
(e.g. `textures/mp/h_yavin`: `sun 1.000000 0.540000 0.629266 180 120 40`).

Acceptance numbers (academy1, seeds_walltest.json — 9 seeds,
fitrun38_sun69, 33 compiles, ~39s): ambient-only 103.31 → final 74.03
(−29.3, better than the −2.0 bar); kept 5/9 (sw_00/02/03/04/05), positions
moved=True; A/B wash 4362 pts, max 65.0/ch; spatial offset 21.24/ch;
diagnostic gain +0.4047 (suggested ~28; the control at sun 28 lands
identically — kept 5, final 74.02 — the absolute value is absorbed by the
model offset, the directional SHAPE is what's baked).

Face-level shape check (probe vs no-sky A/B, face-level mean over matched
faces): the baked wash is ~0 at lightmap level (the wash is runtime-applied
by the sky shader — `q3map_nolightmap` on the sky shader) and the interior
fit is flat across directions (interior south 80.5/ch vs north 84.4/ch vs
floor 77.0/ch, probe vs orig 101.1/64.4/100.6 — the original's south-strong
/ north-weak profile is carried by the sun key direction in both bakes,
120°/40°; the fit's interior stack is radially symmetric by design). The
shape check is therefore "verified by construction", not by a lightmap
profile. Default unchanged: skyLight 130; the sun path is opt-in. Changing
the default is the owner's call.
